# nixos-anywhere Session — 2026-05-20

## What was done

### 1. Added disko config (required by nixos-anywhere)

nixos-anywhere needs a `disko` configuration to partition the disk. Without it the command fails.

- Added `disko` input to `flake.nix`
- Created `modules/hosts/saradomin/disk.nix` — GPT layout on `/dev/nvme0n1`:
  - 512MB EFI (`/boot/efi`, vfat)
  - 8GB swap
  - Rest (~503GB) → root `/` (ext4)
- Removed UUID-based `fileSystems` and `swapDevices` from `hardware.nix` (disko owns these now)
- Imported `saradominDisk` in `modules/hosts/saradomin/configuration.nix`

### 2. Fixed unrelated niri evaluation error

`modules/packages/niri.nix` was evaluating the `niri` package for `aarch64-darwin`, which is Linux-only. Fixed with:
```nix
lib.optionalAttrs (lib.hasSuffix "-linux" system) { ... }
```

### 3. Prepared extra-files for age key

nixos-anywhere wipes the disk, so the sops age key must be passed via `--extra-files`:
```bash
mkdir -p /tmp/saradomin-extra/var/lib/sops-age
cp <age-private-key> /tmp/saradomin-extra/var/lib/sops-age/keys.txt
chmod 600 /tmp/saradomin-extra/var/lib/sops-age/keys.txt
```

### 4. nixos-anywhere run — kexec succeeded, install incomplete

The command ran and kexec booted saradomin into the NixOS installer environment successfully. However, the machine is only reachable via **Tailscale DNS** (`saradomin`), and Tailscale is not running in the installer environment. SSH timed out because the hostname didn't resolve to anything reachable.

The session was abandoned because the user was not on the local network.

**The Debian install on the disk was NOT touched** — kexec is in-memory only. The machine booted back to Debian normally (or will after a timeout/reboot).

## What to do when back home

Run nixos-anywhere again using the **local LAN IP** (not the Tailscale hostname):

```bash
# 1. Find saradomin's LAN IP from your router's DHCP leases

# 2. Recreate extra-files if /tmp was cleared
mkdir -p /tmp/saradomin-extra/var/lib/sops-age
# paste age private key from Bitwarden:
echo "AGE-SECRET-KEY-..." > /tmp/saradomin-extra/var/lib/sops-age/keys.txt
chmod 600 /tmp/saradomin-extra/var/lib/sops-age/keys.txt

# 3. Run nixos-anywhere with LAN IP
nix run github:nix-community/nixos-anywhere -- \
  --flake .#saradomin \
  --extra-files /tmp/saradomin-extra \
  --sudo \
  --target-host felipe@192.168.x.x
```

After install and reboot, SSH in as `felipe` (not root) using the `zaros` private key:
```bash
ssh felipe@192.168.x.x
sudo systemctl status k3s
```

## Key facts about the config

- SSH authorized keys are **static** (`keys/zaros.pub`, `keys/bitbaut.pub`) — not managed by sops. SSH access survives even if sops fails on first boot.
- `PasswordAuthentication` is disabled by NixOS default — need the zaros private key.
- sops age key path: `/var/lib/sops-age/keys.txt`
- Disk device: `/dev/nvme0n1` (confirmed NVMe, not SATA despite `ahci` in kernel modules — those were generated by nixos-generate-config on Debian)
